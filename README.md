# Muggun Technologies – Corporate Website

Muggun Technologies is a modern, responsive corporate website developed as part of a technical website development assignment. The website presents the company's services, company information, internship and live project opportunities, and contact details.

## Local Setup Instructions

### Requirements
- XAMPP
- Visual Studio Code or any code editor
- A modern web browser
- Internet connection for Bootstrap CDN

### Installation Steps
1. Install and open XAMPP.
2. Copy the project folder into the 'htdoc' directory.
3. Ensure the project folder is named `muggun-dev`.
4. Start Apache from the XAMPP Control Panel.
5. Open your browser and visit:

   `http://localhost/muggun-dev/`

6. Navigate through the website using the navigation menu.

## Contact Form Notice
The contact form is frontend-only. It displays demo feedback and does not send or store messages because backend integration and database connectivity are outside the scope of this assignment.
